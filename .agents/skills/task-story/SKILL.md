# Task Story

Write only concise user stories that include the actors, their actions, and the desired outcomes. A task can have multiple stories for each user involved

Example: As a GM, I want to create a game, so I can prepare a session.


Write the result to `docs/tasks/<task>/story.md`, using the existing task directory or a descriptive kebab-case name. Preserve unrelated work and ask before overwriting it.
