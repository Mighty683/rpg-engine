# Class management — user story

**Created:** 2026-11-12

As a GM, I want to create and manage Fabula Ultima classes in a library outside any game, including their free benefits and skills, so that I can reuse classes I enter from a source or create myself across games.

As a GM, I want to copy a library class into a game and edit that game's copy separately, so that library changes do not alter running games.

As a GM, I want class management to look and work the same in the library and in a game, so that I can manage either version without learning a different workflow.

As a GM, I want to see which characters use a game class skill before removing it and confirm its removal from those characters, so that I understand the consequences of changing a class in play.

As a player, I want to see my character's benefits, so that I can understand what the character gains from their classes and skills.

As a GM, I want to define benefits as either descriptions or modifiers to stats supported by the game engine, so that the application can apply supported effects while still recording effects that require human interpretation.

The application starts without precreated classes. A character's benefits are listed; supported stat modifiers affect the character's stats, while text benefits describe effects that cannot easily be represented in the engine.
