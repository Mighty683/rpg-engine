# GM and player separation — user stories

**Created:** 2026-11-06

As a GM, I want to manage a game in my GM role, so I can prepare and run it for the players. I want to have control over whole game

As a player, I want to participate in a game in my player role, so I can manage my character and take part in the game. I want to have control over my part of game and view of others.
