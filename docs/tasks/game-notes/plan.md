Record results in handover and archive the implemented task with working links. |

Use one separate subagent per wave during implementation. Make the preceding increment and its verification available before starting its dependent wave. Preserve other workers' edits. If a contract decision changes, update the canonical schema, task contract, consumers and affected acceptance checks together.

Run `pnpm --filter @rpg-engine/tests test:api --run` and `pnpm --filter @rpg-engine/tests test --run` with a disposable TEST_DATABASE_URL. The final integration command is `pnpm verify`. Determine colocated unit coverage alongside the implementation.
