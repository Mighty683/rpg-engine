# Game notes — user story

**Created:** 2026-11-18

As a GM, I want a private notebook per game with rich-text entries, so I can capture plans, secrets and session details during prep and play.

As a GM, I want recent entries reachable from the table in a drawer, so I can consult them without leaving play.

As a GM, I want to search the whole notebook by text and browse entries newest first, so I can find what a scene needs and load more as I scroll.

As a GM, I want entries to autosave with editable recovery on failure or conflict, so I never lose what I typed.

As a GM, I want the Agent to answer questions from my saved notes in the game's private chat, so I can recall established details without rereading the notebook.

As a player, I never see GM notes, so the GM can keep secrets and twists private.
