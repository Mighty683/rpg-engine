## Delivered scope

The first screen lists saved games and provides game creation. A game requires a trimmed name of at most 20 characters and a permanent RPG-system association, saved in PostgreSQL. Unfinished setup remains in memory and is lost on reload or restart. Player workflows, opening or editing games, system setup, identity, and AI actions remain outside this task.

## Resolved foundations

- Initial catalog: Dungeons & Dragons 5e, stable ID `dnd-5e`; rules implementation remains separate.
- Identity: UUID generated by the backend; duplicate names remain valid.
- Persistence: PostgreSQL, parameterized queries, and an initial SQL migration. Local database configuration, migration, and startup commands are documented in the [README](../../../README.md).
- HTTP contracts: list games, list available systems, and create a game; validation and error responses follow the [technical design](tech.md).
